# Русский бренд

Медиа о российских брендах: истории создателей, интервью, обзоры и новости индустрии.

Сделано на [Astro](https://astro.build) + Tailwind CSS v4 + MDX. Деплой через GitHub Actions на GitHub Pages.

## Концепт оформления раздела «Русский бренд»

Брендированное оформление рубрики внутри СМИ2: «русская редакционная роскошь» на стыке
трёх культурных кодов по ролям — **исконно-русское** (фактура: ажурные боковые поля),
**имперское** (композиция: симметрия, рамки, матовое золото), **советское** (акцент:
конструктивистские бейджи, плакатный красный). Без матрёшек и хохломы.

- **3 направления вживую.** Переключатель внизу страницы: **Имперский / Редакционный / Советский**.
  Базовое — **редакционное** (синтез 60/25/15). Направление меняется через `html[data-dir=...]`,
  перестраивая только CSS-токены. Выбор сохраняется в localStorage.
- **Стайлборд + UI-kit:** страница **`/styleguide`** — палитра, типографика, декор, бейджи,
  карточки, ссылки на одном экране.
- **Боковые ажурные поля** видны при ширине окна **≥1280px**; на мобильном схлопываются,
  верх/низ держат ажурные кромки шапки и футера.

Ключевые файлы концепта: `src/styles/global.css` (токены направлений + брендовые классы),
`src/components/` — `Ornament.astro`, `SideRails.astro`, `Divider.astro`, `DirectionSwitcher.astro`,
`Header.astro`, `ArticleCard.astro`; страница `src/pages/styleguide.astro`.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть [http://localhost:4321](http://localhost:4321).

## Как добавить статью

1. Создайте `.md` или `.mdx` файл в нужной папке:
   - `src/content/stories/` — истории брендов
   - `src/content/interviews/` — интервью с основателями
   - `src/content/reviews/` — обзоры и подборки
   - `src/content/news/` — новости индустрии
2. Заполните frontmatter:

   ```markdown
   ---
   title: "Заголовок"
   description: "Короткое описание для превью и SEO"
   pubDate: 2026-05-21
   author: "Имя автора"
   cover: "/covers/название-картинки.svg"
   coverAlt: "Описание обложки"
   tags: ["тег1", "тег2"]
   draft: false
   ---

   Текст статьи в Markdown.
   ```

3. Положите обложку в `public/covers/`.
4. Закоммитьте и запушьте — деплой произойдёт автоматически.

## Структура

- `src/pages/` — страницы и маршруты
- `src/layouts/` — общие шаблоны
- `src/components/` — переиспользуемые блоки
- `src/content/` — статьи в Markdown
- `src/content.config.ts` — схемы коллекций
- `src/consts.ts` — общие константы (название, рубрики)
