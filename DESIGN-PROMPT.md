# Русский бренд — промпт для новой версии дизайна

Готовый к вставке промпт. Просит **новую версию** оформления (свежую интерпретацию
того же культурного кода, а не повтор существующего решения). Копируй блок целиком
в новую сессию.

```
Ты — арт-директор и продуктовый дизайнер. Сделай НОВУЮ версию визуального оформления
раздела «Русский бренд» — брендированной рубрики внутри СМИ2 (референс smi2.ru/publisher/3058).
Это медиа о российских брендах: истории создателей, интервью, обзоры, новости.
Не копируй прошлое решение — предложи свежую интерпретацию того же кода.

СТЕК: Astro + Tailwind CSS v4 + MDX. Компонентная архитектура, CSS-токены темы.

КОНЦЕПЦИЯ: «русская редакционная роскошь» — НЕ сувенирный фолк. Три культурных слоя
смешаны ПО ФУНКЦИИ, а не как декор. Опорная пропорция — примерно:
  • ~60% editorial/digital — чистая редакционная сетка, воздух, сильная типографика
  • ~25% имперское — симметрия, рамки, матовое типографское золото, ощущение статуса
  • ~15% советское — конструктивистская геометрия, плакатный красный (скупо)
Ты можешь осознанно сместить эту пропорцию, если так сильнее — но обоснуй выбор.

КУЛЬТУРНЫЙ СЛОВАРЬ (источники формы, не буквальные картинки):
вологодское кружево, красный фолк-силуэт, конструктивистский шрифт («УТРО»),
резные деревянные вертикальные панели.
ЗАПРЕЩЕНО: матрёшки, балалайки, хохлома, буквальный лубок, клюква.

ЧТО НУЖНО СПРОЕКТИРОВАТЬ:
  1. Палитра и её роли (фон / текст / акцент / металл). Отталкивайся от связки
     «молочный крем + чернила/графит + бордо + матовое золото», но предложи свой строй.
  2. Типографическая пара/тройка (serif-заголовки + UI + конструктивистский кондансед).
     Можешь взять Cormorant Garamond / Inter / Oswald или предложить лучше — с аргументом.
  3. Система mood-направлений: минимум 2–3 живых варианта тона (например
     editorial / imperial / soviet) через data-атрибут на <html>, переопределяющий
     только CSS-токены в рантайме, с сохранением выбора. Базовое — самое сбалансированное.
  4. Декоративный кит: боковые ажурные поля на широких экранах со сворачиванием на мобиле,
     розетка/делитель, клеймо-марка, угловые скобки карточек, бейджи рубрик.
  5. Логотип-марка: одноцветная (currentColor), геометрическая, работает как клеймо
     мастера и как аватар до 24px. Предложи новую идею марки.
  6. Ключевые экраны: шапка-плашка, лента карточек статьи, страница статьи, /styleguide
     (палитра, типографика, декор, бейджи, карточки на одном экране).

ОГРАНИЧЕНИЯ КАЧЕСТВА: адаптивность, focus-visible, prefers-reduced-motion,
тач-таргеты ≥44px, уникальные id SVG-паттернов, никакого «AI-slop» (лишние тени,
градиенты-желе, безликие стоковые иконки).

СГЕНЕРИРУЙ 3 РАЗНЫХ НАПРАВЛЕНИЯ КОНЦЕПТА и покажи их рядом для сравнения:
каждое — со своим настроением, палитрой и пропорцией слоёв, чтобы можно было выбрать.

ФОРМАТ ОТВЕТА (для каждого из 3 направлений):
  1) Краткий концепт новой версии (2–3 абзаца): чем отличается от «дефолтной русской
     роскоши», какое настроение, какая пропорция слоёв и почему.
  2) Дизайн-система: палитра (hex + роли), шрифты, шкала типографики, spacing, motion.
  3) Описание декоративного кита и марки.
  4) Готовые CSS-токены (:root + data-dir оверрайды) и разметку/классы ключевых
     компонентов (шапка, карточка, бейдж, делитель, боковые поля).
```

> Тот же результат «варианты рядом + структурный фидбэк» автоматизирует скилл
> `/design-shotgun` (см. `DESIGN-PIPELINE.md`).
