# Русский бренд — v2, 3 направления концепта (design spec)

**Дата:** 2026-07-02 · **Ветка:** `design/v2-concepts` (форк от `main` @08dd826)

Свежая интерпретация того же кода по `DESIGN-PROMPT.md`, на **утверждённых заказчиком
материалах**: логотип-наличник (`public/logo/lockup*.svg`) + палитра из логотипа
(крем `#FFFCF4`, чернила `#2C2825`, бордо `#9B080E`).

Задача: **3 разных направления концепта рядом** для выбора. Каждое — своё настроение,
палитра и пропорция культурных слоёв (editorial / imperial / soviet). Отдаём страницей
сравнения `/concepts`: сводка сверху (палитры + шрифты рядом) + 3 «живых» полосы, где
концепт применён к реальному контенту (шапка-плашка × СМИ2, hero-статья, лента карточек,
делитель). Логотип везде — утверждённый наличник, тинтуется под концепт.

## Направление 1 — «Наличник / Резьба» · imperial через дерево · ~50/35/15
Тёплое, тактильное, резное. Наличник — структурный мотив: обложки обрамляются как окна,
боковые поля = резные вертикальные панели. Золото только акцентом.
- Палитра: тёплый крем `#FBF3E6` / поверхность `#F4EADA` · орех-чернила `#33251A` /
  `#6B4E34` · бордо `#9B080E` · матовое золото `#A8823C` · линия `#D8C4A6`.
- Шрифты: Cormorant (заголовки, serif-first) · Inter (UI) · Oswald (надзаголовки/бейджи).
- Настроение: наследие, «смотришь в окно на русский бренд».

## Направление 2 — «Утро / Конструктив» · soviet · ~55/15/30
Смелое конструктивистское медиа. Плакатный бордо работает **структурно** (крупные блоки),
кондансед-заголовки, асимметричная сетка, диагонали. Декор срезан — наличник = чистое
клеймо-аватар. Золото отсутствует.
- Палитра: крем `#F3F1EA` · near-black `#17140F` · бордо-плакат `#9B080E` (много) ·
  линия `#DAD5C8`. Золото не используется.
- Шрифты: Oswald (крупный дисплей) · Inter (UI) · Cormorant (минимально, в тексте).
- Настроение: энергия, манифест, «бренд как заявление».

## Направление 3 — «Золото / Империя» · imperial через металл · ~45/45/10
Церемониальная имперская роскошь. Матовое типографское золото доминирует, тёмные
чернильные фоны в шапке/hero, золочёные рамки и хайрлайны, строгая симметрия. Дворец/музей.
- Палитра: тёмный чернильный фон `#161009` / `#20180E` · крем-контент `#F5EEDF` ·
  золото `#C6A25E` / `#B79154` · бордо глубокий `#7A1518` · линия-золото `rgba(198,162,94,.4)`.
- Шрифты: Cormorant (церемониальные заголовки) · Inter (UI) · Oswald (мелкие капс-лейблы).
- Настроение: статус, музейное золото, «императорский поставщик».

## Компоненты (в каждой полосе)
Шапка-плашка (наличник × СМИ2 + дескриптор) · hero-статья (обложка + титул + дата,
по мотиву утверждённого макета) · лента 2–3 карточек (угловые скобки + бейдж рубрики) ·
делитель-розетка.

## Качество
Адаптив, focus-visible, prefers-reduced-motion, тач-таргеты ≥44px, уникальные id
SVG-паттернов, без AI-slop. Токены скоупятся на обёртку концепта (`[data-c]`), не на `:root`,
чтобы 3 системы жили на одной странице одновременно.

## Картинки
Первый проход — реальная обложка статьи (hotlink) как общий hero + существующие SVG-обложки
в карточках. Бесшовные бренд-hero под каждое направление — опционально через Higgsfield
(nano-banana / generate_image) после выбора.
